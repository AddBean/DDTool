# Lucide icons

These SVGs are the unmodified icons from Lucide `0.468.0`, vendored so desktop packages can render them offline. The upstream source is `https://github.com/lucide-icons/lucide/tree/0.468.0/icons`; see `LICENSE` for the upstream ISC and Feather notices.

To add an icon, copy its SVG from the same upstream version and reference its filename without `.svg` through `Icon.name` or `WorkButton.iconName`.
